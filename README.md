# 🧩 Block Blast Solver

Aplikasi web interaktif pencari urutan & posisi kotak paling optimal untuk menaruh ke-3 balok pada game **Block Blast**.

🌐 **Live Demo (GitHub Pages):** [https://daffadzakwanpratama.github.io/bloclblastsolver/](https://daffadzakwanpratama.github.io/bloclblastsolver/)

## ✨ Fitur Utama
- **Panduan Langkah 1 → 2 → 3 Visual:** Menampilkan urutan pengambilan balok (`#1`, `#2`, `#3`), koordinat baris & kolom eksak, serta efek *line clear* pada setiap langkah.
- **Scan Screenshot Otomatis (`Ctrl+V` / Upload):** Deteksi otomatis papan 8×8 dan 3 balok dari screenshot layar HP lengkap dengan kalibrasi manual.
- **3 Mode Strategi Solver:** Seimbang (Jaga Streak + Papan Aman), Survival (Anti-Mati & Ruang 3×3), serta Skor & Combo Maksimal.
- **Editor Manual & Katalog Lengkap:** Klik & geser di papan 8×8, pilih dari 37 bentuk balok standar Block Blast, atau gambar bentuk kustom 5×5.

## 🚀 Menjalankan Secara Lokal
```bash
npm install
npm run dev
```
